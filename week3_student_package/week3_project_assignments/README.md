# 3주차 제조·금융 개인·팀 프로젝트

1·2주차에서 선택한 도메인 하나를 골라 진행합니다.

- `option1_manufacturing`: 공장 설비 운영·예지보전 데이터
- `option2_finance`: 금융 가맹점 위험·운영 데이터

두 과제의 처리 흐름은 같습니다.

```text
2주차 요약 데이터
→ 저장된 전처리 규칙 재사용
→ PCA와 분석
→ SQLite 저장·조회
→ FastAPI 제공
→ Streamlit 대시보드
```

## 시작 방법

1. 제조 또는 금융 폴더 중 하나를 선택합니다.
2. 해당 폴더의 `README.md`와 데이터 안내 문서를 먼저 읽습니다.
3. `3주차_*_프로젝트_학생용.ipynb`의 Q1~Q5를 실행합니다.
4. 노트북 Q6에 인사이트 세 문장을 작성합니다.
5. 노트북이 만든 `outputs` 폴더에서 API와 Streamlit 파일을 실행합니다.

학생용 파일에는 정답 노트북과 `_answer` Python 파일을 넣지 않았습니다. 필요한 Python 패키지는 이 폴더의 `requirements.txt`를 사용합니다.

제출할 때는 각 도메인 폴더의 제출 체크리스트를 확인하세요.
