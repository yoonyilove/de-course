# 3주차 수업 데이터

`api_members_fallback.csv`는 2주차의 `member_activity_summary.csv` 첫 100행을 복사한 대체 입력입니다.

- 행: 회원 100명
- 열: 회원 기본정보 7개와 30일 활동 요약 9개
- 사용 이유: 수업 중 FastAPI 서버가 실행되지 않아도 Streamlit·전처리·SQLite·그래프·PCA 실습을 계속할 수 있습니다.
- 기준 파일: `course_materials/week2/outputs/member_activity_summary.csv`

이 파일은 사람의 결혼 가능성이나 가치를 평가하기 위한 자료가 아닙니다. 회원 활동 데이터가 API, 파일, 전처리기, DB와 화면 사이를 이동하는 과정을 연습하기 위한 합성 데이터입니다.
