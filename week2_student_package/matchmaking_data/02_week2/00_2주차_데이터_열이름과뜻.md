# 2주차 데이터 열 이름과 뜻

> 모든 자료는 수업용 합성 데이터입니다. 실제 인물이나 실제 회사 기록이 아닙니다.

## 1주차 데이터와 어떻게 이어지나요?

- 1주차 `matchmaking_members.csv`는 회원 1,000명에 의도적인 중복 3행을 더한 1,003행×21열 파일입니다.
- 2주차 `members.csv`는 같은 회원 ID `M001`~`M1000`을 사용합니다.
- 1주차의 21개 열을 그대로 포함하되, 중복과 연습용 오류를 정리하고 38개 확장 열을 더해 1,000행×59열로 만들었습니다.
- 따라서 두 파일은 완전히 별개의 회원표가 아닙니다. 2주차 `members.csv`는 1주차 회원표를 정리하고 확장한 후속 파일입니다.
- 2주차 필수 실습에서는 59개 열을 모두 사용하지 않습니다. 회원별 활동요약에 붙일 `member_id`, `gender`, `age`, `residence_region`, `membership_tier`, `signup_channel`, `meeting_scheduled`만 직접 사용합니다.

## activity_batches는 왜 25개인가요?

- `activity_batches`는 2주차에 처음 등장하는 일별 활동 로그입니다.
- 회원 1,000명을 40명씩 나누어 파일 하나에 담았습니다.
- 회원 40명×30일 기록이므로 파일 하나는 1,200행입니다.
- 40명 묶음이 25개이므로 전체 회원 수는 1,000명이고, 25개×1,200행은 총 30,000행입니다.
- 파일 하나는 특정 날짜 한 개가 아니라 회원 40명의 30일 기록을 모두 담습니다.
- 25개라는 수는 실제 업무의 고정 규칙이 아니라 `glob`, 반복 읽기, `concat`을 충분히 연습하면서도 파일 수가 지나치게 많지 않도록 정한 수업 설계입니다.

## 활동 로그의 열은 모두 처음 등장하나요?

- `member_id`는 1주차와 같은 회원 ID이므로 새 열이 아닙니다.
- `activity_date`, `logged_in`, `app_opens`, `stay_time_min`, `profile_views`, `recommendations_viewed`, `messages_sent`, `avg_reply_delay_sec`는 2주차에서 처음 사용하는 일별 로그 열입니다.
- `logged_in`과 `profile_views`는 1주차의 `login_week1`~`login_week4`, `profile_views_30d`와 개념적으로 연결되지만 같은 열은 아닙니다. 2주차 값은 하루 단위 원천 기록입니다.

## 수업에서 먼저 기억할 네 가지

- `activity_batches`의 한 행은 **회원 한 명의 하루 활동**입니다.
- 25개 파일을 합치면 30,000행이며, 회원은 1,000명입니다.
- 4교시부터 하루별 여러 행을 회원별 한 행으로 요약합니다.
- `meeting_scheduled`는 만남이 성공했다는 뜻이 아니라, 회사 시스템에 일정이 등록되었다는 뜻입니다.

## 열 사전

| 표/단계 | 열 이름 | 쉬운 뜻 | 자료형·단위 | 수업에서 하는 일 |
|---|---|---|---|---|
| activity_batches | `activity_date` | 활동 날짜 — 회원의 앱 활동이 기록된 날짜 | date · YYYY-MM-DD | 날짜별 파일과 회원별 요약 |
| activity_batches | `member_id` | 회원 ID — 회원 한 명을 구분하는 합성 식별자 | string · M001 형식 | 파일 결합과 회원표 merge의 공통 열 |
| activity_batches | `logged_in` | 로그인 여부 — 그 날짜에 한 번이라도 로그인했는지 | boolean · True/False | 활동일 수 계산 |
| activity_batches | `app_opens` | 앱 실행 횟수 — 그 날짜에 앱을 연 횟수 | integer · 회 | 합계와 스케일링 |
| activity_batches | `stay_time_min` | 앱 체류 시간 — 그 날짜에 앱을 사용한 총 시간. 일부 행에는 '미측정'이 들어 있음 | number/string · 분 또는 미측정 | to_numeric과 결측 대체 |
| activity_batches | `profile_views` | 프로필 조회 수 — 다른 회원의 프로필을 본 횟수. 일부 결측 포함 | number · 회 | 결측 확인과 회원별 합계 |
| activity_batches | `recommendations_viewed` | 추천 열람 수 — 회사에서 제시한 추천 상대를 열어 본 횟수 | integer · 회 | 회원별 합계 |
| activity_batches | `messages_sent` | 메시지 발송 수 — 서비스 안에서 보낸 메시지 횟수 | integer · 건 | 회원별 합계 |
| activity_batches | `avg_reply_delay_sec` | 평균 답장 지연 시간 — 답장이 있었던 날의 평균 답장 소요 시간. 답장이 없으면 비어 있음 | number · 초 | 평균과 결측 대체 |
| 병합 중 생성 | `source_file` | 출처 파일명 — 각 행이 어느 CSV에서 왔는지 남기는 추적용 열 | string · activity_batch_01.csv 형식 | 여러 파일을 합친 뒤 출처 확인 |
| 회원별 요약 | `active_days` | 로그인한 날 수 — 30일 가운데 logged_in이 True인 날의 합계 | integer · 일 | 회원 한 명당 한 행으로 요약 |
| 회원별 요약 | `total_app_opens` | 총 앱 실행 횟수 — 30일 동안 app_opens의 합계 | integer · 회 | 집계와 전처리 |
| 회원별 요약 | `total_stay_time_min` | 총 앱 체류 시간 — 숫자로 바꿀 수 있는 체류 시간의 합계 | number · 분 | 숫자 변환과 집계 |
| 회원별 요약 | `total_profile_views` | 총 프로필 조회 수 — 30일 동안 프로필을 본 횟수의 합계 | number · 회 | 결측 처리 후 집계 |
| 회원별 요약 | `total_recommendations_viewed` | 총 추천 열람 수 — 30일 동안 추천을 열어 본 횟수의 합계 | integer · 회 | 집계와 전처리 |
| 회원별 요약 | `total_messages_sent` | 총 메시지 발송 수 — 30일 동안 보낸 메시지의 합계 | integer · 건 | 집계와 전처리 |
| 회원별 요약 | `avg_reply_delay_sec` | 30일 평균 답장 지연 — 답장이 있었던 날들의 평균 답장 소요 시간 | number · 초 | 결측 대체와 스케일링 |
| 회원별 요약 | `last_active_date` | 마지막 로그인 날짜 — logged_in이 True였던 가장 최근 날짜 | date · YYYY-MM-DD | 최근 활동일 계산 |
| 회원별 요약 | `days_since_last_activity` | 마지막 로그인 후 경과일 — 2026-07-01에서 마지막 로그인 날짜를 뺀 일수 | number · 일 | 모델 입력용 파생변수 |
| members | `gender` | 성별 — 회원이 등록한 성별 | category · 남성/여성 | 범주형 전처리 |
| members | `age` | 나이 — 기준일의 만 나이 | integer · 세 | 수치형 전처리 |
| members | `residence_region` | 거주 지역 — 현재 거주 광역 지역 | category · 서울/경기 등 | 범주형 전처리와 API 필터 |
| members | `membership_tier` | 회원권 등급 — 서비스 이용 요금제 | category · 베이직/프리미엄/VIP | 범주형 전처리와 API 표시 |
| members | `signup_channel` | 가입 경로 — 회원이 서비스를 알게 된 경로 | category · SNS/검색광고 등 | 범주형 전처리 |
| members | `meeting_scheduled` | 만남 일정 등록 여부 — 회사 시스템에 오프라인 만남 일정이 등록되어 있는지 | boolean · True/False | 연습용 정답 y. 실제 만남 성사 여부가 아님 |

## 원본 파일의 나머지 열

`members.csv`, `preferences.csv`, `matches.csv`에는 이후 확장을 위한 열도 들어 있습니다. 2주차 필수 실습에서는 위 표에 적힌 열만 직접 사용합니다. 처음부터 59개 열을 모두 외울 필요는 없습니다.
