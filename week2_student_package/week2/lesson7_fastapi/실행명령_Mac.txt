1. 압축을 푼 뒤 VS Code 또는 Cursor에서 `lesson7_fastapi` 폴더를 엽니다.
   터미널에서 이 폴더로 이동합니다.
cd "압축을 푼 위치/course_materials/week2/lesson7_fastapi"

2. 가상환경을 켭니다.
conda activate de-course

3. 요약 데이터를 준비합니다.
python prepare_api_data.py

4. 학생 파일의 빈칸을 모두 채운 뒤 서버를 켭니다.
python -m uvicorn api_app_student:app --reload --port 8000

5. 브라우저에서 엽니다.
http://127.0.0.1:8000/docs

6. 서버를 끌 때 터미널에서 Control+C를 누릅니다.
