# 1주차 데이터 안내

이 폴더에는 1주차에서 사용하는 CSV와 데이터 설명 자료가 있습니다.

- `matchmaking_members.csv`: 기존 회원 1,003명의 기본 정보와 활동 정보
- `matchmaking_preferences.csv`: 회원별 희망 조건. 6교시에서 `member_id`로 결합합니다.
- `matchmaking_members_new.csv`: 8교시에서 같은 전처리 규칙을 적용해 보는 새 회원 100명
- `data_dictionary_week1.csv`: 열 이름을 빠르게 찾아보는 표
- `1주차_데이터_열이름과뜻_안내슬라이드.pptx`: 열의 뜻과 수업에서 처음 쓰이는 교시를 설명하는 자료

1~3교시는 이 CSV를 바로 읽지 않습니다. 노트북 안의 작은 연습 자료로 Python과 NumPy를
연습한 뒤, 4교시부터 이 폴더의 CSV를 읽습니다. 파일명과 폴더 위치는 바꾸지 마세요.
